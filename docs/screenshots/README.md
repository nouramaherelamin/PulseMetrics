# Genuine screenshot checklist

**Redesign note:** the four existing captures (`overview.png`, `process-explorer.png`, `performance-analytics.png`, `time-machine.png`) show the previous purple/cyan UI. After the PC-monitoring redesign (docs/ui-redesign.md) they must be recaptured from a real Windows run before they are used to describe the current interface; no new screenshot has been fabricated or generated.

Capture manually only after approval; do not fabricate values or use automation.

Requested README assets:
- `overview.png`: live CPU/RAM, freshness and collector health.
- `process-explorer.png`: discovery and a consenting, non-sensitive tracked process.
- `performance-analytics.png`: real source, units, time range and threshold evidence.
- `time-machine.png`: real selected window and supported comparison with visible timestamps/gaps.

Prefer a consistent 1920x1080 or 1366x768 desktop viewport. Before approval inspect usernames, paths, process names, browser tabs, notifications and history for private information. Use non-sensitive real observations; crop unrelated desktop content, and disclose any redaction. Never edit measurements to improve appearance. Add accessible captions identifying the screen and observed state. User UI acceptance does not constitute approval of a particular screenshot for public release.
